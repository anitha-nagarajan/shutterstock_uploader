# Shutterstock Photo Uploader

Automates the metadata generation and CSV preparation for uploading photos to Shutterstock.

## What it does

1. **Analyses** your photos using Claude AI (vision) to generate title, description, keywords, category, and license type
2. **Opens a review UI** in your browser where you can edit and approve metadata per photo
3. **Exports a CSV** formatted for Shutterstock bulk upload, then opens the Shutterstock upload page

---

## One-time Setup

### 1. Install Python dependencies

Open Terminal and run:

```bash
cd path/to/shutterstock_uploader
pip install -r requirements.txt
```

### 2. Set your Anthropic API key

In Terminal, add this to your shell profile (`~/.zshrc` or `~/.bash_profile`):

```bash
export ANTHROPIC_API_KEY="sk-ant-your-key-here"
```

Then reload it:
```bash
source ~/.zshrc
```

## Usage (every time)

### Step 1 — Generate metadata

Point the script at your photos folder:

```bash
python generate_metadata.py /path/to/your/photos
```

This will analyse each photo with Claude AI and save a `_metadata_draft.json` file in your folder. Takes ~5–10 seconds per photo.

### Step 2 — Review and approve

```bash
python review_app.py /path/to/your/photos
```

A browser window opens automatically at `http://localhost:5000`. For each photo you can:
- Edit title, description, keywords, category, license type
- Add/remove keywords by typing in the keyword field
- Click **Approve** when happy
- Click **Approve All** to approve everything at once

### Step 3 — Export and upload

Once you've approved your photos, click **Export CSV & Open Shutterstock**.

This will:
- Download a `shutterstock_upload.csv` file to your photos folder
- Open the Shutterstock bulk upload page in your browser

On the Shutterstock page:
1. Drag & drop your photo files
2. Upload the `shutterstock_upload.csv` file
3. Submit!

├── photo1.jpg
├── photo2.jpg
├── _metadata_draft.json     ← generated by step 1, edited in step 2
└── shutterstock_upload.csv  ← generated in step 3

## Tips

- Run `generate_metadata.py` once per batch. Re-running it will overwrite the draft.
- The review app auto-saves as you edit — no save button needed.
- You can re-open the review app anytime to continue editing before exporting.
- Cost: approximately $0.01–0.03 per photo for Claude API usage.
